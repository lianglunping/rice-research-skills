# Report Research Results

Write a decision-oriented internal report from available verified evidence.
Identify the audience, purpose, research object and current evidence first. An
existing analysis bundle is useful but is not a required file layout. Read source
artifacts directly and state which claims they support.

Default organization: core conclusion, key evidence, limitations or risks, next
step. For a routine supervisor report, use the minimum sufficient length; if
2–3 Word pages suffice, do not add a ten-section report, abstract or contents.
Long manuscripts, formal reviews and required templates determine their own
structure. Move detailed methods and audit evidence into traceable supporting
files without losing information that changes interpretation or reproducibility.

Report biology before statistical ceremony. Preserve cohort/reference/generation
boundaries, statistical units, evidence levels, alternative explanations and
validation conditions. Exploratory trends and candidate priorities must not
become significance, causality, stable inheritance or confirmed mechanisms.
Include negative or uncertain results when they affect the decision.

Explain each included figure using its purpose, observed pattern and supported
interpretation. Cite actual inputs, versions, paths and meaningful parameter
choices. Use question-appropriate inference; do not require `results-analysis`
or a new significance analysis merely to summarize existing work.

Write to the requested or task-owned output location. Use a dated descriptive
filename where helpful. Update Obsidian, project memory or other canonical notes
only when that destination is part of the user's authorized scope; a bound vault
does not by itself authorize additional writes. Do not fabricate experiment
round numbers or automatically propagate conclusions to other records.

Apply the user's Office defaults and inspect the final exported artifact when
delivering DOCX/PPTX/XLSX/PDF. Report concrete remaining checks and next actions.
`references/figure-interpretation.md` and
`references/decision-oriented-analysis.md` are optional aids; extended report
templates and statistical checklists are conditional, not compulsory sections.
