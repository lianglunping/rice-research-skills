# 投稿级 Figure Quality Gates

按图件类型检查适用项。简单单图可在现有任务记录中保留关键证据。

## Gate 1：语义与证据

- [ ] Figure Contract 有一个可回答的 `core_question`。
- [ ] `core_claim` 的强度不超过数据。
- [ ] 每个 panel 有唯一的 `defends`，且关键数字可追溯。
- [ ] 已区分直接观察、条件关联、假设和未来验证。
- [ ] 图例、caption 和正文使用相同样本、分母和术语。
- [ ] 直接声称相互对应的 panel 使用相同数据子集与距离口径；若一个 panel 使用全量数据，差异已明确标注。

## Gate 2：生物学与坐标

- [ ] 样本 ID、材料、家系、世代和检测范围准确。
- [ ] 参考基因组、注释、坐标基准、contig、链和 REF/ALT 已核对。
- [ ] 负链基因的方向解释与显示方向一致。
- [ ] 不把选中交集、共享 reads 或浏览器截图写成独立验证。

## Gate 3：统计

- [ ] 图型符合数据结构和样本量。
- [ ] 个体点、效应量和不确定性按任务需要展示。
- [ ] SD、SEM、CI、IQR 等定义明确。
- [ ] `n`、检验方法、多重校正和阈值明确。
- [ ] 重复测量、技术重复和生物学重复未混淆。
- [ ] 坐标轴和变换诚实；bar 从 0 起，log 明确标注。
- [ ] 保留无显著差异、零效应或不确定的结果，按问题展示观测值、效应量和适当的不确定性。

## Gate 4：Composition

- [ ] 遮住 caption 后，主张仍可从图中读出。
- [ ] 主证据及各 panel 的关系明确；面积与信息密度、阅读任务相称，同等重要的比较允许等权布局。
- [ ] 删除任一辅助 panel 都会削弱论证；否则删除或转补充材料。
- [ ] 阅读顺序清晰，panel 标签、轴和边距对齐。
- [ ] 注释只引导一个主信号，不覆盖数据。

## Gate 5：视觉

- [ ] 白底、无无意义背景网格和装饰。
- [ ] 同一类别跨图同色；连续、发散和分类色标语义正确。
- [ ] 灰度与常见色觉缺陷下仍可区分。
- [ ] 最终尺寸下文字、线宽和点大小可读。
- [ ] 无缺字、裁切、重叠、图例遮挡或低分辨率 raster。
- [ ] 最终渲染无实际字形碰撞、裁切或遮挡；若使用 word-box 筛查，相交和越界告警均已复核，误报有渲染依据。连接线、树枝、节点、坐标轴、符号和图例图形未穿过字形。
- [ ] 表头和分区图例文字按实际字体度量加留白后，完整容纳于各自单元格/指定矩形；页面级无越界不能替代单元格级验收。
- [ ] 每个 panel 内颜色、线型、形状、面积和刻线各有唯一且明确的语义；树图支系与附加分组可区分，外环及其他辅助编码有明确图例。
- [ ] 地图类别构成与总量的编码适合数据密度，聚合前后计数守恒；发生坐标避让时保留原始与绘制坐标、位移说明及必要引线，最终尺寸可辨认。
- [ ] 组合图的 panel 字母、阅读顺序和图注角色逐项一致；地图与树图等关键证据面板未发生错位或误标。
- [ ] 不使用 3D 饼/柱、rainbow/jet 或无物理关系的双 Y 轴。
- [ ] 显微图、表型照片和 read view 有真实比例尺/坐标、方向和必要标签。
- [ ] 图像亮度、对比度或裁剪对同一比较组一致；任何局部增强均有记录。

## Gate 6：复现与交付

- [ ] 脚本从文件读取数据，可用记录的命令重跑。
- [ ] 软件/包版本、seed、输入和输出路径已记录。
- [ ] 派生表与图中数字一致。
- [ ] PDF 和 PNG 非空；需要时有 SVG/TIFF/EPS。
- [ ] 回读 PDF 页面宽高与字体。直接检查文字、线条和点仍为矢量对象。
- [ ] 按嵌入后的物理尺寸计算照片、显微图或其他栅格内容的有效 DPI，核对比例尺与图像一起缩放。
- [ ] 多面板图可重生成各统计 panel，并保留独立可编辑输出。按任务需要提供图注、合同、manifest 和 QA 记录。
- [ ] 输入 checksum 作图前后相同，或变更有明确说明。
- [ ] 交互图或浏览器截图只作辅助，不替代冻结的静态结果和来源表。

## 四轴判断

1. **Depth**：图是否显示“为什么/所以什么”，而非只摆数据。
2. **Elegance**：证据关系清晰，版面和视觉编码服务于核心问题。
3. **Unimpeachable**：不确定性、n、单位、坐标、复现和边界无明显攻击点。
4. **Readability**：在最终尺寸下，文字与关键证据可读，阅读顺序和图例容易理解。

机械脚本只能检查 Gate 6 的一部分。四轴判断必须结合真实渲染图和科研问题人工复核。
