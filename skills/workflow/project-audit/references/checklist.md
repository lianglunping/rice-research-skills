## 常见问题快速检查

### 数据追溯性
- [ ] 样本数在各文件中是否一致
- [ ] 变异数在各文件中是否一致
- [ ] 统计数字是否可从原始数据重算
- [ ] 是否存在孤儿文件或断链

### 代码可靠性
- [ ] 阈值判断是否使用正确的比较符（`>=` vs `>`）
- [ ] 缺失值是否正确处理（`./. ` vs `.` vs `0/0`）
- [ ] 是否存在 off-by-one 错误
- [ ] 是否存在魔法数字

### 文档一致性
- [ ] README 描述与代码实现是否一致
- [ ] 列定义与实际输出是否一致
- [ ] 样本命名是否跨文件统一
- [ ] 版本标识是否跨文件统一

### 方法学合理性
- [ ] 工具选择是否适合物种特征
- [ ] 阈值设置是否有依据
- [ ] 是否存在循环论证
- [ ] 质量指标是否在合理范围

### 结论强度
- [ ] 是否存在过强表述（"证明"、"确认"）
- [ ] 是否存在选择性汇报
- [ ] 是否存在隐含假设
- [ ] 推断性结论是否明确标注

### 可复现性
- [ ] 软件版本是否明确
- [ ] 参考基因组版本是否明确
- [ ] 是否有隐藏的手工步骤
- [ ] 是否提供最小可复现示例

### 交付物完整性
- [ ] 是否包含代码目录
- [ ] 是否包含标准结果文件（.tsv）
- [ ] 是否包含 README 文档
- [ ] README 包含最小必需信息
- [ ] 若有 release 目录，是否与工作目录一致
