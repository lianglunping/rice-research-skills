# Review Lanes

Pick one lane based on the user's actual goal.

| Lane | Use when | Primary concern | Read next |
|---|---|---|---|
| `external` | user wants harsh review, journal-style critique, biggest weaknesses, novelty challenge, or overclaim check | whether the work is convincing to a skeptical outside reader | `external-reviewer.md` |
| `advisor` | user wants supervisor feedback, chapter steering, next-step decisions, or feasibility advice | whether the thesis main line is coherent and finishable | `advisor-reviewer.md` |
| `committee` | user wants pre-defense, degree readiness, committee challenge, or thesis adequacy check | whether the dissertation reaches doctoral-thesis completeness and is defensible | `committee-reviewer.md` |

## Default Inference

- "harsh review", "blind review", "reviewer 2" -> `external`
- "导师会怎么看", "该怎么改更稳", "下一步先补什么" -> `advisor`
- "预答辩", "委员会", "学位论文是否够格" -> `committee`

If the user asks for all three, keep the same source text but produce three separate sections.
