## Consensus Rule

Call something "consensus" only when multiple independent studies, systems, or evidence types support it. Otherwise use "emerging pattern", "single-paper claim", or "tentative model".

## Evidence Scope Values

Use one of:

- `single-paper`
- `paired-notes`
- `review-only`
- `multi-paper`
- `mixed-original-and-review`
