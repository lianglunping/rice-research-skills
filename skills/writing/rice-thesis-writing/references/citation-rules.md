# Citation Rules

Use this file when normalizing thesis citations and chapter reference lists.

## Hard constraints

- Never invent author names, DOI, URL, page numbers, volume or issue numbers, publishers, publication places, conference names, access dates, or document types.
- If a field is missing and cannot be verified, keep only the confirmed fields and mark it for author review.
- When a source looks suspicious but cannot be safely corrected, preserve the fact layer and note the risk in a format note.

## In-text citation rules

Default target for the current thesis task: **author-year style**.

- Chinese single author: `（汪学军，2005）`
- Chinese two authors: `（张三、李四，2024）`
- Chinese three or more authors: `（肖玲等，2024）`
- English single author: `（Wang，2022）`
- English two authors: `（Smith and Jones，2022）`
- English three or more authors: `（Jenkins et al.，2012）`

### General rules

- Always use round brackets.
- Use a Chinese comma between author and year.
- Chinese two-author citations list both names.
- Chinese three-or-more-author citations use `等`.
- English two-author citations use `and`.
- English three-or-more-author citations use `et al.`.
- Multiple citations in one place:
  - sort by ascending year,
  - if years match, sort by author order,
  - separate with Chinese semicolons.

## Reference list rules

- Prefer a **chapter-level independent reference list** when requested.
- Remove duplicate entries and merge alternate spellings of the same source.
- Keep Chinese author names in Chinese and English author names in English.
- Use GB/T 7714-2015 author-year spirit for field order and punctuation, but do not fabricate missing fields.

## Missing-field handling

When a reference is incomplete, use one of these notes in the format note section:

- `该参考文献字段缺失，请作者核实。`
- `该参考文献信息存在疑似错误，但当前无法安全判定，请作者核实。`

## Typical cleanup targets

- Convert raw numbered placeholders like `[1]` only after the author-year mapping is reliable.
- Remove duplicated bare URLs once the formal reference entry is retained.
- If a source can be identified only by title plus URL, keep that limited form and mark the missing fields.
