# Report Structure

Write in Chinese by default. Keep gene names, software names, file names, variables, and identifiers in English.

## Required Report

1. **TL;DR**
   - Research object and pain point.
   - Core finding.
   - Mechanism, method, breeding, or bioinformatics value.
2. **Paper Identity and Latest Context**
   - Metadata, author roles if available, journal/year, field position.
   - External progress is allowed by default for whole-field context, author-team follow-up, and Discussion follow-up unless the user disables it; label `[外部检索补充]`.
3. **Author Story Reconstructed From Main Figures**
   - Figure-by-figure storyline table.
   - If the paper is method-, benchmark-, or breeding-evaluation centric, explicitly state that the central logic is design/performance/resource generation rather than a single molecular mechanism.
4. **Abstract and Background Logic**
   - Context, problem, strategy, results, conclusion.
5. **Methods and Technical Stack**
   - Materials, phenotyping, wet-lab methods, omics pipeline, statistics, genetics.
   - Prioritize load-bearing parameters tied to the paper's central claims. Do not serially restate every method subsection when it adds little interpretive value.
   - Mark missing parameters as `【原文未提供】`.
6. **Figure-Driven Evidence Audit**
   - Figure-level role.
   - Panel inventory.
   - Panel relationships.
   - Evidence strength and limitations.
7. **Results Claim Map**
   - Claims mapped to panels/tables/methods/statistics.
8. **Discussion Close Reading**
   - Author interpretation vs data-supported conclusion vs speculation.
9. **Critical Evidence Audit**
   - Strongest evidence, weakest link, alternative explanations, overreach.
   - Explicitly downgrade broad conservation, extension, or application figures when they are mechanistically weaker than the paper's core evidence chain.
   - For method or breeding-evaluation papers, judge whether the evidence really supports the recommended dose/design/resource claim and how far it generalizes across backgrounds, environments, or crops.
10. **Breeding, Bioinformatics, and Mutagenesis Relevance**
   - Practical value and boundary conditions.
11. **Research Seeds and Transferable Lessons**
   - Actionable questions, minimum validation, risks.
12. **Glossary**
   - 10-20 core terms: definition, biological meaning, paper-specific use.
13. **Zotero/Obsidian Dry-Run Plan**
   - Notes, tags, citekey, review schedule.
14. **Quality Self-Assessment**
   - Missing information, unresolved uncertainty, figure parsing limits, external search status.

End with: "如需针对某一生信流程细节、特定 Figure 的分子实验胶图、或 Discussion 中的某个推断做进一步深挖，请回复对应章节编号、图号或关键词。"
