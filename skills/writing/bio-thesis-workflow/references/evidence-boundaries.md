# Evidence Boundaries

This file defines the hard guardrails for all outputs generated by `bio-thesis-workflow`.

## Allowed

- reorganization of supported claims
- compression of repetitive wording
- cautious interpretation clearly tied to inputs
- explicit uncertainty labels
- placeholders such as `【待补证】` when evidence is missing

## Not Allowed

- fabricated references or metadata
- invented statistical significance
- invented gene functions or pathway roles
- invented experimental settings, doses, sample sizes, sequencing depth, or validation status
- replacing quantitative statements with vague praise

## Claim Labels

Use these labels internally while drafting:

- `direct`: fully stated by the source artifact
- `supported`: reasonable synthesis across multiple source artifacts
- `tentative`: plausible but not yet demonstrated

Only `direct` and `supported` should appear as ordinary thesis prose. `tentative` should be explicitly marked as inference or future work.

## Source Traceability

Whenever practical, retain one or more of the following in notes, metadata, or nearby context:
- input path
- table name
- figure panel
- README name
- run manifest

## Numerical Discipline

- Preserve original precision unless there is a clear normalization reason.
- Do not silently round values that may alter interpretation.
- If two sources disagree, do not reconcile by guessing. State the discrepancy.

## Domain-Specific Reminders

- Mutagenesis breeding studies often contain descriptive patterns that are tempting to over-interpret. Keep causality restrained.
- Omics context correlations are not mechanisms by default.
- Candidate-gene lists are prioritization artifacts, not proof of gene function.
