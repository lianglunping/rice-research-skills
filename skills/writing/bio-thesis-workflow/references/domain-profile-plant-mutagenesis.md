# Domain Profile: Plant Mutagenesis And Omics

Use this profile when the writing task touches rice, plant genetics, mutagenesis breeding, or omics interpretation.

## Preferred Context Frames

- material and generation: `M1`, `M2`, `M3`, backcross, validation set
- mutagen source: heavy ion, gamma ray, EMS, fast neutron, CRISPR comparison
- evidence chain: raw mutation discovery, strict filtering, known-variant removal, annotation, candidate prioritization, validation
- omics bridge: WGS, WES, RNA-seq, ATAC-seq, multi-omics integration

## Preferred Terminology

- use `heavy-ion mutagenesis` rather than vague `radiation treatment` when known
- use `candidate gene prioritization` rather than `target gene discovery` unless validated
- use `descriptive evidence`, `enrichment pattern`, `relative depletion`, `cross-generation fixation`, `chimerism`, `functional-region distribution`

## Phrases To Avoid

- "breakthrough discovery"
- "perfectly demonstrates"
- "fully reveals the mechanism"
- "proves the breeding value"
- "comprehensively explains all observed patterns"

## Safer Alternatives

- "provides a basis for"
- "is consistent with"
- "supports the following interpretation"
- "suggests a possible explanation"
- "requires further validation"

## Common Logic For This Domain

1. mutagen exposure creates DNA damage
2. repair pathway choice shapes the retained mutation spectrum
3. M1 material may be chimeric
4. fixed inheritance requires later-generation validation
5. annotation and functional-region summaries prioritize follow-up work, but do not replace validation

## Writing Reminders

- When comparing reference systems, explain what each reference contributes.
- When discussing candidate genes, separate annotation support from phenotype proof.
- When discussing chromatin accessibility, distinguish overlap, association, and mechanism.
