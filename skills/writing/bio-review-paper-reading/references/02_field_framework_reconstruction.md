# Field Framework Reconstruction

Do not summarize section order mechanically. Build a clearer framework from the review.

## Framework Fields

```yaml
field_question:
why_this_field_matters:
core_concepts:
historical_stages:
mechanism_layers:
technology_layers:
data_layers:
breeding_or_application_layers:
current_bottlenecks:
review_author_lens:
```

## Reconstruction Moves

- Group scattered content into biological layers, technical layers, data layers, and application layers.
- Separate established facts from tentative models.
- Identify the review's hidden organizing axis: mechanism, trait, organism, data type, method, or application.
- If the paper is loose or repetitive, state that the following framework is `[原文重构]`.

## Plant and Rice Lens

Add when relevant:

```yaml
crop_relevance:
rice_specific_relevance:
molecular_breeding_relevance:
bioinformatics_relevance:
mutagenesis_breeding_relevance:
translation_risk:
```

Avoid overstating rice relevance when the review mainly covers Arabidopsis, animal systems, or general methods.
