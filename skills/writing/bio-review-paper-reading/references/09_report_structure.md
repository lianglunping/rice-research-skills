# Report Structure

Write in Chinese by default. Keep gene names, software names, file names, variables, and identifiers in English.

## Required Report

1. **TL;DR**
   - Field boundary.
   - Core framework or route.
   - Key gap.
2. **Bibliographic Profile and Latest Progress**
   - Metadata, author lens, journal/year, time-point meaning.
   - External progress is allowed by default for latest context, stale reviews, controversies, and author-team follow-up unless the user disables it; label `[外部检索补充]`.
3. **Abstract Deep Dive**
   - Background, bottleneck, motivation, scope, framework, conclusion.
4. **Motivation and Field Evolution**
   - Why this review was needed.
   - 2-4 historical stages if supported or reconstructable.
5. **Core Framework and Knowledge Taxonomy**
   - Classification logic and core modules.
6. **Route Divergence and Method/Mechanism Comparisons**
   - Key routes and when each applies.
7. **Consensus, Controversies, and Open Gaps**
   - Separate established consensus from tentative models.
8. **Figure and Table Decoding**
   - Conceptual figures, models, timelines, and comparison tables.
9. **Published-After Update**
   - Confirmed, corrected, contradicted, replaced, or unresolved claims.
10. **Research Proposal Seeds**
   - Core question, why now, minimum path, major risk.
11. **Glossary and Hubs**
   - 8-15 terms, pathways, methods, or concepts.
12. **Zotero/Obsidian Dry-Run Plan**
   - Notes, tags, citekey, review schedule.
13. **Quality Self-Assessment**
   - Framework completeness, evidence labeling, external update limits, remaining backtracking queue.

End with: "如需针对文中的某张关键图、某类技术路线的横向对比，或某个争议点做进一步深挖，请直接回复对应章节编号、图号或关键词。"
