# Interpretation Rules — 结果解读规则

## 1. Tier 分级（按 meanQval 实际阈值）

| Tier | meanQval | 含义 | 建议 |
|------|----------|------|------|
| A | < 0.025 | 高置信（对应经验上的 ~q<0.025 FDR 阈值） | 优先投入下游验证资源 |
| B | [0.025, 0.035) | 中等置信 | 需扩群验证 |
| C | [0.035, 0.05] | 待验证候选 | 结合其他证据判断 |

**禁止**: 按"top-N by maxGprime"划分 Tier（会掩盖 q 值差异）。

## 2. 方向性（v2.1 re-polarize 后）

- **+ΔSNP** → HighBulk (高表型池) 富集 **Va-like 等位** (Va 贡献)
- **−ΔSNP** → HighBulk 富集 **Vv-like 等位** (Vv 贡献, 多基因性状常见)

**历史陷阱**: v1 未 re-polarize, ΔSNP 方向仅对应 REF/ALT, 不直接映射到 Va/Vv; v2.1 修复后方向与亲本贡献一致（DEC-015）。

## 3. 端粒峰警示

**触发**: `posMaxGprime` 在染色体端 ±100kb 内

**解读**:
- 端粒/亚端粒区 **低重组率** → LD 扩展 → 伪宽峰
- 因果变异可能位于峰值 **左侧 1-5 Mb** 或更远
- 建议候选基因按距峰值距离分层（0-1 Mb / 1-3 Mb / 3+ Mb）

**报告用语**: "chr5 qtl16 峰值 25,021,533 位于 chr5 组装末端，端粒低重组可能造成伪宽峰，因果变异位置需谨慎判断"

## 4. 染色体级 Stratification 警示

**触发**: 单个 QTL 长度 / 染色体长度 > 50%

**解读**:
- 该信号更可能是 **染色体级 stratification / LD 块**
- 不是真 QTL，而是整条染色体的 AF 偏差
- 通过多方法验证（QTLseq CI + 敏感性）

**示例**: 葡萄项目 chr11 qtl5 (11.16 Mb / chr11 共 19 Mb = 58%)，在 QTLseq 95% CI 下未检出，建议剔除。

**报告用语**: "chr11 qtl5 在 QTLseq 95% CI 方法下未获独立支持，疑似染色体级 stratification 或 LD 块，建议从优先候选中剔除"

## 5. 多方法交集逻辑

QTL 置信度优先级（高→低）:

1. **Gprime q<0.01 ∩ QTLseq 99% CI** — 最高置信（罕见，小样本通常为空）
2. **Gprime q<0.05 ∩ QTLseq 95% CI**（fallback 主交付）
3. **Gprime q<0.05 alone** — 次级，需警惕假阳性
4. **QTLseq 95% CI alone** — 通常方法更严，优先于 Gprime alone

Top 候选应在**多方法交集**中出现。

## 6. 小样本声明强制语

n < 50 / 池时，所有交付文档必须含：

> "本研究 bulkSize=N 低于 QTL-seq 方法学文献推荐的 ≥50（理想 ≥400; Takagi 2013; Mansfeld 2018）。识别到的区间为**候选信号**（candidate intervals），**非已定位的 QTL**，需扩群或独立标记验证方可进入基因克隆阶段。"

## 7. 禁用词汇表（Gate 4 人工项 A2）

| 禁用 | 替换为 |
|------|--------|
| "定位到 N 个 QTL" | "识别出 N 个候选区间" |
| "主效 QTL" | "信号最强的候选区间" |
| "候选基因" (仅区间内基因) | "区间内注释基因 (待功能筛选)" |
| "可直接基因克隆" | "适合优先做标记验证和候选基因功能筛选" |
| "抗旱 QTL 已确认" | "与抗旱性关联的候选信号" |
| "DeepVariant 严格过滤" | "按 QTLseqr 标准流程过滤" |
| "方向与 Va 一致 ✅" | "方向与 Va 纯合等位一致（统计符号，未做生物学验证）" |

## 8. 假阳性预期声明

q=0.05 fallback 时必须声明:

> "FDR 5% 意味着 N 个区间中预期 ≈ N × 0.05 个假阳性。建议用 QTLseq 95% CI 的 M 个区间做交集筛选，被两种方法共同检出的区间可信度更高。"

## 9. pseudo-pool 边界声明

所有交付文档 LIMITATIONS §3.1 强制含:

> "本研究为 pseudo-pool（40 个体逐个测序后按池 AD/DP 加和），在个体间测序深度均一假设下近似等同于物理混池测序。若个体间 DP 差异大，等效 bulkSize 会降低。per-sample DP 均一性 QC 见 figures/00_diagnostic.pdf 第 5 页。"

## 10. 多时间点对比解读

- **共识 QTL** (两时间点均显著): 最高置信，可直接进入 KASP 精细定位
- **时间特异 QTL**: 可能反映早期 vs 晚期响应机制差异，需生物学验证
- **方向相反 QTL**: 警示信号——可能表型测量口径不一致或样本标注错位，客户必须先确认 phenotype_source.meta.yaml 一致性再解读
