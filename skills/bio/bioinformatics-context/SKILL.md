# 水稻分子育种与生物信息学判断框架

用于明确生物学问题、证据边界和验证方向。具体工具、参数和命令按需交给专项 skill；不把背景知识当作项目已经核验的结果。

## 先明确问题与材料

- 写明需要支持的判断：描述变异、定位候选、判断遗传、解释机制，还是选择育种材料。
- 核对材料名称、亲本、家系、世代、处理、选择历史、测序批次、参考及原始文件路径。
- 区分个体、家系、混池、生物学重复和技术重复；确定实际统计单位与比较分母。
- 原始输入保持不变，派生结果进入可追踪目录；保留来源、命令、软件版本、关键参数和适用的随机种子。
- 趋势与多类证据一致性可支持探索性候选排序；明确替代解释及验证条件，不自动升级为因果、稳定遗传或已确认机制。

## 参考、注释与检测边界

| 要素 | 要核验的内容 | 对判断的影响 |
|------|--------------|--------------|
| 参考组装 | 实际 FASTA、版本、校验值、contig 名称与长度 | 坐标与 REF 必须与该文件一致 |
| 基因注释 | GFF/GTF 来源、版本、所依赖组装、基因与转录本 ID | 组装和注释是不同版本对象，不能仅凭 MSU/RAP 名称互换坐标 |
| 材料与参考差异 | 群体背景、局部缺失、重复区、比对质量 | 评估参考偏倚，不默认某一参考适合所有材料 |
| 检测能力 | 测序或捕获范围、覆盖度、变异类型、过滤与缺失 | 决定可支持的分母与阴性结论 |

基因组大小、基因数量、重复比例及 ID 对应关系从项目实际版本计算或核验来源，不维护无版本的通用数值。换参考或引入泛基因组时同步检查注释、坐标转换和验证数据。

`callable`、多重检验与功效分析由问题决定：

- 突变率、富集或耗竭、缺失判断及依赖检测分母的定量比较，要评估检测范围和可比性；分母不可靠时报告偏倚并降低结论强度。
- 已观测变异目录、描述性分布、候选排序、注释和单个位点验证可继续推进，不因缺少 callable 而机械阻断；不能外推为全基因组发生率或“未发生”。
- 按假设数量、探索或验证目标及错误代价决定多重检验；正式大规模推断不能无理由省略，单一描述任务也不机械套用。

## 按问题选择分析方法

| 场景 | 设计与验收重点 |
|------|----------------|
| SNP/InDel 检测 | FASTQ 与比对 QC、材料倍性和杂合度、亲本与背景比较、分类型规范化、基因型证据和局部验证。VQSR 或硬过滤需依据当前工具文档、训练资源与本项目分布选择，不照搬其他物种的阈值。 |
| SV 与复杂重排 | 联合 junction、read depth、局部组装等证据；校准 caller、合并规则及断点容差。保留原始调用、union、支持数和可解释 singleton，不固定要求两个 caller 支持。复杂候选按问题安排长读长、组装或断点实验。 |
| BSA/QTL-seq | 先核对群体设计、遗传预期、表型分组和混池代表性，再决定池大小、测序量、窗口及适配模型的模拟或置换；按标记密度和定位分辨率检验参数敏感性。 |
| GWAS | 根据群体结构、亲缘、等位基因频率、效应和样本量选择模型；区分混合模型与多位点方法。用本群体 LD 和实际标记覆盖定义候选范围，不使用固定水稻 LD 距离。 |
| RNA-seq | 确认设计矩阵、批次与混杂、独立重复、计数与归一化口径；报告效应量及不确定性。效应和显著性筛选阈值由生物学问题与预定分析目标决定。 |
| 诱变候选定位 | 结合处理、表型、亲本和世代区分背景多态与候选新变异。频率用于优先级判断，不无条件删除共有或单 caller 事件；不以诱变类型预先排除其他变异类别。 |

深度、群体规模、重复数和过滤阈值需要项目依据。不得把人类 benchmark、示例参数或经验范围写成水稻通用验收门。

## 验证路线与结论层级

- **变异存在性**：根据事件类型选择 Sanger、分型、断点 PCR、拷贝数检测或长读长证据；明确各方法实际覆盖的位点、等位基因和结构。
- **共分离与遗传**：结合交配设计、表型测量、外显率、连锁及家系结构提出可检验预期。不能仅凭预设分离比或固定株数宣称遗传模式成立。
- **表达与功能**：表达变化是相关证据；遗传互补、编辑或其他扰动的解释需结合对照、遗传背景、独立事件及表型恢复或重现，不能只按实验名称固定评级。
- **育种效果**：在目标遗传背景和环境验证效应、稳定性、农艺代价与连锁累赘；一次分子检测不能替代表型和材料评价。

候选排序同时考虑效应方向与大小、重复出现、跨材料或跨证据一致性、机制合理性和数据质量。共享 reads 或相同样本的技术复核不能冒充独立生物学验证。

## 标记与育种决策

| 决策 | 依据 |
|------|------|
| InDel、KASP、CAPS/dCAPS 等标记选择 | 位点适配性、分型准确性、目标群体多态性、设备、通量和当前报价，不设置脱离任务的固定优先级 |
| 前景选择 | 验证目标位点或连锁标记的判别力，并评估重组导致的误判 |
| 背景选择与近等基因系 | 使用实测背景标记、目标区段和残留供体片段；回交世代不能单独保证基因组恢复率、纯合度或近等基因系资格 |
| 表型与区试 | 按性状、试验设计和适用的现行规范执行；引用标准前联网核对版本与适用范围 |
| 成本与周期 | 依据当前服务报价、材料生育期和实验条件估计，写明日期、假设与不确定性 |

优先呈现能影响验证或育种决策的主要信号。数据完整性、材料淘汰、不可逆操作和重大资源投入仍需相称复核；不要用无关的形式检查遮蔽生物学问题。
