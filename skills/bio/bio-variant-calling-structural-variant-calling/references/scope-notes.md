# Scientific scope and usage context

Preserved from the installed description during the 2026-09-05 entry cleanup.
These notes qualify method selection; they do not grant tool or write authority.

Design, install, execute, merge, benchmark, or audit reproducible germline structural-variant calling from paired-end short-read WGS, including isolated software environments, caller portfolio selection and operation, per-caller normalization, SVDB/SURVIVOR/Truvari integration, union and support-tagged ensemble views, truth-set calibration, graph-versus-linear alignment tests, cohort genotyping, and rice or induced-mutant transfer. Use when requests mention installing or running short-read SV software, Manta, Dysgu, Delly, LUMPY/Smoove, GRIDSS, SvABA, SURVIVOR, SVDB, Truvari, caller consensus, VCF/BCF harmonization, ensemble merging, graph genome alignment, or benchmarking deletions, insertions, duplications, inversions, and breakends. Do not use as the primary workflow for long reads, SNP/indel calling, read-depth-only CNV analysis, targeted/WES data, or somatic cancer interpretation.
